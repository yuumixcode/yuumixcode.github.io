## 收录原则

本站的 AI 笔记只写**对实际工作有用的判断**,不堆教程:

- 一个外部 AI skill / 工具进来,先回答三件事:**它产什么 / 它的产物和我站结构对不对得上 / 怎么用最低成本合进来**
- 优先记录**和本站 Zensical 技术栈强相关**的集成方式(目录约定、iframe 嵌入、生成产物归档路径)
- 不收录需要付费账号、cookie 横幅、或在 GitHub Pages 部署边界外跑的内容
