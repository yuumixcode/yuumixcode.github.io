# 入门与许可证

Odin Inspector and Serializer 是 Sirenix 开发的 Unity 编辑器扩展插件，三大核心能力：

- 通过**特性（Attribute）**快速增强 Inspector 面板显示
- **扩展 Unity 原生序列化**，支持字典、委托等原生不支持的类型
- 提供**自定义 Drawer 系统**，深度定制编辑器 GUI

> 适用版本：**Odin Inspector 3.3.1.10+**（Unity 6 LTS / 团结引擎）。
> 范围：仅 Odin Inspector，不包含 Odin Toolkit 与 Aesir Inspector。

## 什么是 Odin Inspector

Sirenix 出品的 Unity 编辑器扩展，核心是「特性增强 + 序列化扩展 + 自定义 Drawer」三位一体。

## 生态合作

- **Rider 合作**：Rider 2024.1 起原生支持 Odin 字符串引用校验，强烈推荐 Rider 做 Unity + Odin 开发。
