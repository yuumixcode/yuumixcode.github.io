## 查看建议(样式参考角度)

- **Hermes Agent / OpenClaw 这类 2026 新贵**:共同套路是「一句话定位 + 安装命令块(curl | bash)+ 能力矩阵卡片 + Discord/GitHub 双 CTA + star 数背书」。
- **Ollama / Aider / OpenCode**:极简单页,靠文案和终端截图说话,适合个人项目模仿。
- **n8n / Dify / Firecrawl**:标准 SaaS 多屏 landing,有 pricing、customer logo 墙,信息密度高。
- **RAGFlow / LightRAG**:GitHub README 直接当产品页,Docs 站(VitePress/MkDocs 风格)承担官网职能。

## Unity 生态的样式结论

- **国产开源框架几乎都没有"产品页"**:ET、QFramework、GameFrameX、Luban 全靠 GitHub README + Docs 站(YooAsset 是唯一有像样独立官网的)。→ 谁能做出 Hermes/OpenClaw 那种 landing page,谁在传播上就赢。
- **商业插件(Unity 圈审美天花板)**:看 Staggart Creations、More Mountains、Sirenix、Unity/Godot/Unreal 官网。共同点:深色底、全屏游戏截图/视频、一处强调色、大留白、GIF 动效演示、清晰的 Buy/Docs 双 CTA。
- **对你的启发**:个人 Unity 工具站最值得抄的是 More Mountains(独立开发者、产品线多、页面克制)和 OpenClaw(hero + 命令块 + 能力卡片 + star 背书)。
